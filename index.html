Готово. Для AI-карты глубины нужен интернет при первом запуске. На телефоне модель может загружаться дольше.

AI-карта строится моделью Depth Anything V2 в браузере. Первое использование требует интернета для загрузки модели. Для наиболее объёмного результата нажми «Создать 3D-глубину»: резервный режим использует лишь плавный градиент и не заменяет AI. Сильное движение может растягивать края, потому что скрытые за объектами области не существуют в исходной картинке.
